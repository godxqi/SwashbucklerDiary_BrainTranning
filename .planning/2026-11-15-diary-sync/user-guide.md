# 日记同步用户说明

## 同步什么

| 会同步 | 说明 |
|---|---|
| 日记正文 | 含标题、心情、天气、位置、置顶标记 |
| 模板 | 与日记走同一条通道 |
| 标签 | 随日记携带；同名标签会自动合并 |
| 复盘数据 | 15 张表：日课/周课/月课、目标、阻断、限制性观念、敌人、美德、肯定、归档、状态记录、课题、日课人物行 |
| 地点 | 自建地点字典 |
| 附件 | **默认关闭**，可在同步页打开。图片/音频/视频 |

## 不同步什么

| 不同步 | 原因 |
|---|---|
| 所有设置项 | 主题、锁屏密码、WebDAV 配置两端打架，比不同步更糟 |
| 隐私模式库 | 独立数据库；隐私模式下同步入口直接禁用 |
| 头像 | 头像路径在设置里，只同步文件会让另一端不知道用哪张图 |
| 日志、成就、用户状态 | 可由日记重建，同步反而引入冲突 |
| 附件（默认） | 坚果云免费版流量有限，图片会很快吃光额度 |

## 第一次使用

### 1. 配置坚果云

1. 浏览器登录 [坚果云](https://www.jianguoyun.com)
2. 右上角头像 → **账户设置** → **安全选项** → **第三方应用管理**
3. 添加应用，生成**应用密码**（不是登录密码）
4. 在 App 里：我的 → 备份 → WebDAV → 配置
   - 服务器地址：`https://dav.jianguoyun.com/dav/`
   - 账号：坚果云注册邮箱
   - 密码：上一步的应用密码

### 2. 同步

我的 → 备份 → **Sync** → 「立即同步」。

首次同步会把本机所有日记和复盘数据上传到 `SwashbucklerDiary/Sync/`。1000 篇日记大约需要 2–3 分钟。

### 3. 第二台设备

装好 App、配置同一个坚果云账号，点「立即同步」，会下载另一台上传的内容。

## 同步规则

### 修改

同一篇日记两端都改过时：

1. 时间戳较新的版本生效
2. 较旧的版本**不会消失**，会保存为「冲突副本」日记：
   - 标题带「（冲突副本 2026-11-15 14:30）」
   - 正文开头注明来自哪台设备
3. 复盘数据按行合并，两端改不同行都会保留

### 删除

删除会同步到另一端，**不会复活**。

墓碑保留 90 天。超过 90 天未开机的设备，可能把已删除的数据重新带回来——这是所有离线同步系统的固有限制。

### 冲突

两台设备同时点同步时，后提交的一方会收到「另一台设备刚刚提交过同步」，自动重试一次；仍失败时提示稍后重试，不会写坏数据。

## 文件在哪

坚果云 `SwashbucklerDiary/Sync/`：

```
manifest.json              索引，唯一的提交点
diaries/{id}.json          每篇日记一个文件
review.json                复盘数据（15 张表）
locations.json             地点
assets/Image/...           附件（开启后）
```

## 流量

| 内容 | 典型大小 |
|---|---|
| 1000 篇纯文字日记 | 2–5 MB |
| 复盘数据 | 几百 KB |
| 图片/音频 | 按实际大小 |

坚果云免费版每月约上传 1 GB、下载 3 GB。纯文字同步一年也用不了多少；**附件是流量大头**，建议只在 Wi-Fi 下开启。

## 排障

- **同步页 → 诊断**：检查 WebDAV 目录、写入、ETag、条件写是否正常
- **同步前自动备份**：本机 `SyncBackups/` 目录保留最近 3 份整库备份
- **弹窗错误**：会显示前 3 条失败对象；完整列表在日志里
- **常见错误**
  - 「配置失败，请检查配置信息」：账号或应用密码错误
  - 「另一台设备刚刚提交过同步」：并发冲突，稍后重试
  - 「云端数据结构版本不一致」：两端 App 版本差距过大，需要整库覆盖

## 已知限制

1. 不做字段级合并：A 改标题、B 改正文，整篇 LWW。
2. 复盘同一行两端都改，新的覆盖旧的（不生成副本）。
3. 隐私模式库不参与同步。
4. 附件单文件上限 500 MB。
5. 首次同步无「以哪端为准」选项——默认合并，避免覆盖丢数据。
